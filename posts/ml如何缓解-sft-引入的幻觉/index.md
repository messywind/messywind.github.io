# 如何缓解 SFT 引入的幻觉



## SFT 引入的幻觉：成因与缓解机制

&gt; 面试题：**如何缓解 SFT 引入的幻觉？**
&gt; 答这题的关键不是背 5 条手段，而是先讲清楚 **「SFT 为什么会引入幻觉」** 这个机制，再用「数据层 / 生成层 / 系统层」三段式把缓解手段串成逻辑链。

---

## 一、核心机制：SFT 为什么会「引入」幻觉？

预训练阶段模型学到的是「**它知道什么**」；SFT 阶段做的是**行为克隆（Behavior Cloning）**——用交叉熵 loss 强迫模型去拟合标注答案的输出分布。问题就出在这里：

&gt; 当训练样本的答案包含了**模型在预训练阶段并未掌握的知识**（具体人名、日期、数字、API 细节等）时，
&gt; SFT 的 loss 会强迫模型在「**它本该不确定**」的地方也输出一个**斩钉截铁的答案**。

模型学到的**不是这条具体知识**，而是一种**行为模式**：

```
遇到这类问题  →  要自信地输出一个答案（哪怕是编的）
```

这就是 John Schulman 的经典论点：**SFT 在教模型「幻觉的格式」**。模型并没有真的学会事实，而是学会了「在知识边界之外也要假装知道」。

| 阶段 | 学到的东西 | 与幻觉的关系 |
|------|-----------|-------------|
| Pretrain | 知识本身（它知道什么） | 决定了模型的「知识边界」 |
| SFT（行为克隆） | 回答的格式与行为模式 | 若答案超出知识边界 → **奖励了「自信瞎编」** |

**一句话本质**：幻觉的根因是 **监督信号奖励了「超出模型能力的自信」**。下面 5 条手段，本质都是围绕同一目标——**让监督信号不再奖励边界外的瞎编**。

## 二、五种缓解手段（按三层框架归纳）

```
                  SFT 幻觉缓解
                       │
      ┌────────────────┼────────────────┐
   数据层            生成层            系统层
  (从源头控制)     (让过程可验证)    (推理时兜底)
      │                │                │
  ① 清洗数据        ② CoT &#43; 引用      ④ 外部知识 RAG
  ③ 不引入新知识                      ⑤ 不确定性表达
      │                                  │
  (附:honesty data) ─────────────────  (与⑤配套)
```

### ① 清洗训练数据 ——【数据层】

要做两件事：

1. **去掉事实性错误的样本**：标注答案本身就是错的，模型学了直接复制错误。
2. **对齐答案与模型自身的知识边界**（更关键）：尽量让答案落在模型预训练已掌握的范围内，避免大量「模型根本不知道、却被强行教会自信回答」的样本。

&gt; 工业常用技巧 **knowledge-consistent / honesty data**：用模型自己采样，答得出来的留作正例；答不出来的，**把目标答案改成「我不确定 / 我不知道」**，而不是硬塞一个事实进去。

### ② 增加输出前的推理过程 或 增加引用 ——【生成层】

- **增加推理过程 = CoT（思维链）**：让模型先推理再给结论，提供一个「自我验证」缓冲，减少一步到位的瞎猜。
- **增加引用 `xx [来源1][来源2]…` = Attribution / Citation**：训练模型养成标注信息来源的习惯，让答案**可溯源、可核查**，并在训练阶段强化「有据才答」的行为，抑制无中生有。

&gt; 两者本质相同：**让生成过程更可约束、更可验证**。

### ③ 不要过度引入新知识 ——【数据层 / 训练策略】

和 ① 呼应，但角度是「训练定位」：

&gt; SFT 的定位应该是 **对齐格式、激发已有能力（Alignment / Format）**，
&gt; 而**不是灌输新知识（Knowledge Injection）**。

若 SFT 数据塞了大量预训练没覆盖的新事实，等于系统性地训练模型「在陌生领域也硬答」，幻觉被放大。要补新知识，正确做法是 **继续预训练（Continual Pretraining）** 或 **上 RAG**，而非靠 SFT 硬塞。

### ④ 使用外部知识 ——【系统层】

即 **RAG / 工具调用（Tool Use）**：

&gt; 与其逼模型从参数里「回忆」可能不记得的事实，不如让它去检索知识库、调 API、查数据库，
&gt; **把「记忆任务」转成「阅读理解任务」**。

模型基于检索到的上下文作答，幻觉率显著下降。**Agent 场景下尤其重要**——核心就是让 Agent 学会「不知道就去查」，而不是凭参数硬答。

### ⑤ 不确定性表达 ——【系统层 / 行为兜底】

训练模型在**知识边界之外时主动说「我不确定 / 我不知道 / 这部分无法确认」**，即：

- **Abstention（拒答 / 弃权）**
- **Calibration（置信度校准）**

&gt; 与 ① 的 honesty data 配套：**数据层准备「我不知道」样本 → 行为层让模型在低置信时坦诚表达**。
&gt; 原则：**宁可承认不知道，也别幻觉一个答案。**

## 三、三层框架总览表

| 层级 | 手段 | 对应图中 | 解决的问题 | 关键词 |
|------|------|---------|-----------|--------|
| **数据层**（源头控制） | ① 清洗数据 | ① | 错误样本 &#43; 知识边界错配 | Honesty Data |
| **数据层**（训练定位） | ③ 不引入新知识 | ③ | SFT 被误用为知识注入 | Alignment ≠ Injection |
| **生成层**（过程可验证） | ② CoT &#43; 引用 | ② | 一步到位的瞎猜、无据可溯 | CoT / Attribution |
| **系统层**（外部增强） | ④ 外部知识 | ④ | 参数记忆不可靠 | RAG / Tool Use |
| **系统层**（行为兜底） | ⑤ 不确定性表达 | ⑤ | 边界外仍强行作答 | Abstention / Calibration |

## 四、关键代码示意：构造 Honesty Data（①⑤ 配套）

```python
# 思路：用模型自己采样，过滤出「它答不出来」的样本，
# 把目标答案改成拒答，而不是硬塞事实，从源头避免奖励「自信瞎编」。

def build_honesty_sample(model, question, gold_answer, n_samples=8):
    &#34;&#34;&#34;
    对每个问题多次采样，判断模型是否「真的掌握」这条知识。
    掌握 -&gt; 保留 gold_answer 作为正例
    不掌握 -&gt; 目标改为拒答(I don&#39;t know)，教模型坦诚表达不确定性
    &#34;&#34;&#34;
    samples = [model.generate(question) for _ in range(n_samples)]

    # 命中率：模型采样答案中与标准答案一致的比例
    hit_rate = sum(is_correct(s, gold_answer) for s in samples) / n_samples

    if hit_rate &gt;= 0.5:
        # 模型本就掌握 -&gt; 用标准答案，强化「有把握就答」
        target = gold_answer
    else:
        # 模型不掌握 -&gt; 改为拒答，避免训练出「边界外自信瞎编」
        target = &#34;抱歉，我无法确认这个问题的准确答案。&#34;  # 不确定性表达

    return {&#34;instruction&#34;: question, &#34;output&#34;: target}
```

&gt; 要点：**不是删掉难样本，而是把目标答案替换为「诚实的不确定表达」**——
&gt; 这样既不丢数据量，又把「自信瞎编」的监督信号改成了「坦诚拒答」的监督信号。

## 五、面试话术（推荐串讲逻辑）

&gt; **不要平铺直叙五点，按下面这条逻辑链讲，体现你理解了本质：**

「SFT 引入幻觉的**根因**是行为克隆——它强迫模型在知识边界外也自信作答，学到的是『幻觉的格式』而非事实本身。

所以缓解思路分**三层**：

- **数据层**：清洗数据、控制新知识引入、补充诚实样本（对应 ①③）。让监督信号本身不奖励边界外的自信。
- **生成/训练层**：用 CoT 和引用让生成过程可验证（②）。
- **推理/系统层**：用 RAG 引入外部知识、用拒答和置信度表达兜底（④⑤）。

三层从**源头**到**兜底**层层递进。」

## 六、高频追问 &amp; 答题要点

**Q1：为什么继续预训练能补知识，而 SFT 不行？**
A：SFT 数据量小、且 loss 是行为克隆，目的是对齐格式而非记忆事实。强行用 SFT 灌新知识，模型学到的是「在该领域要自信作答」的行为，而非知识本身，反而放大幻觉。补知识应走 Continual Pretraining（大规模、知识密度高）或 RAG。

**Q2：CoT 一定能减少幻觉吗？**
A：不绝对。CoT 提供推理缓冲、利于自我验证，多数事实/推理任务有帮助；但若推理链本身基于错误前提，反而可能「一本正经地把错误推到底」（幻觉的连锁放大）。所以 CoT 常需配合引用/检索一起用。

**Q3：RAG 就能彻底解决幻觉吗？**
A：不能。RAG 把「记忆」转成「阅读理解」，显著降低参数幻觉，但引入新问题：检索召回不全、检索到错误/过时文档、模型不忠实于检索内容（仍然瞎编）。需配合 ⑤ 不确定性表达 &#43; 忠实度（faithfulness）约束。

**Q4：① 清洗数据 和 ⑤ 不确定性表达 有什么关系？**
A：互为配套。① 在**数据层**准备「我不知道」的诚实样本（honesty data）；⑤ 在**行为层**让模型在低置信时收敛到坦诚表达。没有 ① 的数据，⑤ 的行为学不出来。

**Q5：和 RLHF/DPO 对齐阶段缓解幻觉有什么区别？**
A：本笔记五点主要在 **SFT 阶段**从数据和生成方式入手；RLHF/DPO 是在**偏好对齐阶段**，通过奖励模型对「诚实/有据」的回答打高分、对「自信瞎编」打低分，从优化目标上进一步抑制幻觉。两者互补：SFT 立行为基线，RL 阶段做精细校准。
